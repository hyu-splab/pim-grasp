# UPMEM Kernel Driver

`upmem-driver-2024.2.0/` is the source of the UPMEM kernel driver 2024.2.0, Copyright UPMEM. Each
source file states its license in its header: GPL-2.0, a BSD-style license, or a choice of both.
`COPYING` holds the text of the GPL-2.0, and `LICENSE` holds the UPMEM BSD-style license, taken from
the UPMEM SDK source.

See the top-level `README.md` for installation.
